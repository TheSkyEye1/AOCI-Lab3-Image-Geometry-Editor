# Лабораторная работа №3. Геометрические преобразования изображений на C# WPF и Emgu.CV (АОЦИ)

Это учебный проект, демонстрирующий алгоритмы геометрических преобразований изображений (масштабирование, поворот, сдвиг) и методы интерполяции с использованием библиотеки Emgu.CV в десктопном приложении на C# и WPF.

## Функционал
Приложение позволяет выполнять геометрические трансформации и применять художественные деформации:

*   **Геометрические преобразования (Прямой и Обратный методы):**
    *   Масштабирование.
    *   Вращение на заданный угол.
    *   Сдвиг по осям X и Y.
    *   Перенос.
*   **Методы борьбы с артефактами:**
    *   Регулировка размера кисти (для прямого метода).
    *   Фильтрация пропусков (Gap Filtering) — заполнение черных "дыр" цветом соседей.
    *   Билинейная интерполяция (для обратного метода).
*   **Спецэффекты:**
    *   Волны (горизонтальное синусоидальное искажение).
    *   Эффект "Стекло" (сложное искажение по двум осям).

## Ключевые концепции, продемонстрированные в работе
Этот проект акцентирует внимание на различиях подходов к трансформации растра:

*   **Прямое vs Обратное отображение:**
    *   В работе наглядно показана проблема **прямого преобразования**, когда при увеличении или повороте образуются пустые пиксели ("дыры"). Реализованы алгоритмы их "закрашивания" (увеличение размера кисти, усреднение соседей).
    *   Реализовано **обратное преобразование**, являющееся профессиональным стандартом, так как оно гарантирует вычисление цвета для каждого пикселя результирующего изображения без пропусков.
*   **Интерполяция:**
    *   Для повышения качества изображения при обратном преобразовании (когда координаты исходного пикселя получаются дробными) реализован алгоритм **билинейной интерполяции**. Цвет вычисляется как взвешенное среднее четырех соседних пикселей, что дает плавные границы без "лесенок".
*   **Математическая основа трансформаций:**
    *   Код демонстрирует ручной расчет координат с использованием тригонометрии (синусы и косинусы для вращения) и матричных преобразований (для сдвига и масштабирования), реализованных через вложенные циклы `for`.
